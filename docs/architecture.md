# Architecture

*Fictional process plant in the Gabès industrial zone. All parameters are simulation assumptions. No measurement originates from a real company.*

```
configs/*.yaml ──► sim/ (true state) ──► inject/physical ──► sim/sensors (independent paths, meter computes P/Q/S/kWh)
                                          ▲                     │
                                          │                     ▼
                                   events.csv (truth)   inject/sensor · falsification · data_quality · comm
                                                                │
                                                                ▼
                                               data/generated/<run>/measurements.csv  (model input only)
                                                                │
       ┌────────────────────────────────────────────────────────┘
       ▼
 Stage A  detect/      physics/relations R1-R10 → residuals (robust z) → |z| / EWMA / CUSUM flags
                       + validity checks + Isolation Forest   (all fitted on the normal-only block)
 Stage B  diagnose/    episodes per evidence family → features → signature matrix + 2-of-3 current vote
 Stage C  confidence/  evidence → raw confidence → isotonic calibration (validation block) → abstention
          governance/  policy table → tier (AUTO / APPROVAL / IMMEDIATE) → provenance labels
          explain/     template explanation (no LLM)
          audit/       SHA-256 hash-chained JSONL
 Output   data/processed/<run>/  cases.csv, case_details.jsonl, trusted_stream.csv.gz, fingerprint.csv.gz,
                                 audit_log.jsonl, *_calibration.json, latency.json
          evaluate/    reports/metrics.{json,md}         app/  Streamlit dashboard (reads outputs only)
```

## Golden rules → where they are enforced

| Rule | Mechanism |
|---|---|
| Physical events modify the true state; sensor faults only the measured channel | `inject/physical.py` edits simulator drivers before `sim/plant.compute_true_state`; `inject/sensor.py` edits raw sensed signals / meter outputs only |
| No ground truth in model inputs | `measurements.csv` columns fixed by `schema.MEASUREMENT_COLUMNS`; leakage test `tests/test_m2_injection.py`; `op_state` is the *commanded* PLC state, computed before physical events |
| Meter computes everything from its own CT | `sim/sensors.meter_compute`; CT drift is applied before it (`inject/sensor.apply_raw`), so R1/R2 hold during drift (tested) |
| SANAD never actuates | Router outputs advisory/data-gating actions only; the demo controller is an external what-if (`demo/controllers.py`) |
| No LLM decides | Explanations are templates (`explain/templates.py`) filled with named evidence |
| Traceability | Every hypothesis is a list of named rules; fired rules, top relations and held relations are stored per case and in the audit log |
| Reproducible | All randomness via `config.rng_for(cfg, *keys)` (seed + stream name); byte-identical output tested |
| No invented results | `reports/metrics.md` is generated by `cli evaluate`; demo narrative numbers are computed by `demo/scenarios.py` |

## Key design decisions

* **Relations as residuals, normalised on normal data.** z = (r − median) / (1.4826·MAD), floored to each relation's
  physical resolution. A causal median-of-3 removes single-minute spikes; z is clipped at ±8 before EWMA/CUSUM so one
  outlier cannot raise an alarm. EWMA and CUSUM thresholds are 1.3 × the maximum seen on the normal block (floored).
* **Learned structural constants (normal block only):** bus balance P_bus = a + b·ΣP_feeders (R4/R5B), thermal-gain
  correction of R6, vibration load envelopes (R10E), static meter voltage offsets (R8), path baselines for voting.
* **Independent paths.** R6 (thermal), R7 (speed) and R10E (vibration envelope) use a load estimate rebuilt from the
  *relay* CT, so a drifting meter CT does not leak into them. R8/R9 compare each meter with the median of the *other*
  meters (needs ≥ 3).
* **Evidence families.** Alarms are grouped per family (data, electrical, energy, thermal, speed, mech). Short episodes of
  physically coupled families merge (e.g. electrical+thermal for a relay CT bias); a multi-day episode (bearing wear,
  drift) never swallows unrelated short events; data-gap episodes absorb their own side effects. Gaps while a motor is
  stopped do not split an episode.
* **2-of-3 voting on current:** meter CT vs relay CT vs bus-implied current ((P_bus − a)/b − Σ other feeders). The odd one
  out is the faulty path; fewer than three paths → abstain (`FEW_REDUNDANT_PATHS`). Assumes one faulty feeder meter at a
  time (the scheduler never overlaps two CT drifts).
* **Confidence.** Raw = score_top / (Σ scores + null mass). Isotonic calibration on validation cases, shrunk toward the
  raw score with a 20-case prior. Abstain if calibrated < 0.60, margin < 0.15, out-of-distribution (Isolation-Forest score
  below its training range **and** relations violated that the hypothesis does not explain), or too few redundant paths.

## Real-data mode (Phase 2)

`adapters/steel.py`, `adapters/pvgis.py`, `adapters/paderborn.py` implement the `DataSourceAdapter` interface as TODO stubs.
They will feed the simulator *drivers* (load envelope, ambient, vibration health ratios) so that every downstream file
keeps the synthetic schema.
